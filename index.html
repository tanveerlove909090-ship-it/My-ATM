Quick setup checklist

  1. Create a Supabase project and run supabase/schema.sql in SQL Editor.
  2. In Supabase Authentication, enable email/password. Create your owner account through this page.
  3. In SQL Editor, assign the owner role to your exact account using the command in README.md.
  4. Put your Project URL and anon/public key into the configuration section in this HTML file.
  5. Upload the public folder to Cloudflare Pages or another static host.
  6. Test with a separate customer account. Do not use real money until you have verified all permissions and your payment process.

Hosting makes the page public; Supabase provides the database and authentication. This starter does not integrate any payment provider.
